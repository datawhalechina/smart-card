好，那我给你从 **HTTP 100 到 500** 每一个状态码，用**大白话**解释一遍，顺便加点轻松吐槽，方便你记。
（HTTP 状态码分成五类：1xx 信息类、2xx 成功类、3xx 重定向类、4xx 客户端错误类、5xx 服务器错误类）

---

## **1xx 信息类（我收到啦，你继续）**

* **100 Continue** → “好的我收到你的请求头，你可以继续把请求体发过来。”
* **101 Switching Protocols** → “咱俩换个说话方式吧，比如切到 WebSocket。”
* **102 Processing** → “我在忙着处理呢，等会儿哈。”
* **103 Early Hints** → “我先偷偷告诉你一些资源地址，你可以先去预加载。”

---

## **2xx 成功类（OK，搞定）**

* **200 OK** → “一切顺利，给你想要的内容。”
* **201 Created** → “创建成功，比如你新建了一条记录。”
* **202 Accepted** → “我先收下，慢慢处理，结果晚点再告诉你。”
* **203 Non-Authoritative Information** → “内容给你了，不过我只是转述，可能不全靠谱。”
* **204 No Content** → “处理好了，但没啥内容给你。”
* **205 Reset Content** → “处理完了，你刷新/重置一下界面吧。”
* **206 Partial Content** → “这是你要的一部分，剩下的分批发给你。”

---

## **3xx 重定向类（走那边去）**

* **300 Multiple Choices** → “有好几个可选链接，你自己挑一个。”
* **301 Moved Permanently** → “搬家啦，以后都来新地址吧。”
* **302 Found** → “临时搬家，这次去新地址，下次还用老的。”
* **303 See Other** → “你去看看另一个链接的结果。”
* **304 Not Modified** → “内容没变，用你本地缓存就好。”
* **305 Use Proxy** → “必须通过代理才能访问。”
* **307 Temporary Redirect** → “临时换个地址，请求方式不变。”
* **308 Permanent Redirect** → “永久搬家，请求方式不变。”

---

## **4xx 客户端错误类（你的锅）**

* **400 Bad Request** → “请求有问题，我看不懂。”
* **401 Unauthorized** → “你没登录或者 token 过期了。”
* **402 Payment Required** → “先付钱，再给你内容（现在几乎不用）。”
* **403 Forbidden** → “我认识你，但不让你看这个内容。”
* **404 Not Found** → “找不到你要的东西。”
* **405 Method Not Allowed** → “这个接口不支持你用的请求方法。”
* **406 Not Acceptable** → “我能返回的格式，和你要求的不匹配。”
* **407 Proxy Authentication Required** → “请先在代理服务器那儿验证身份。”
* **408 Request Timeout** → “你磨蹭太久，我等不下去了。”
* **409 Conflict** → “请求和当前资源状态冲突，比如版本冲突。”
* **410 Gone** → “资源彻底没了，别找了。”
* **411 Length Required** → “你得告诉我请求体多长。”
* **412 Precondition Failed** → “你设的前提条件没满足。”
* **413 Payload Too Large** → “请求体太大了，我消化不了。”
* **414 URI Too Long** → “URL 太长了，缩短点。”
* **415 Unsupported Media Type** → “我不认识这种格式。”
* **416 Range Not Satisfiable** → “你要的内容范围不对。”
* **417 Expectation Failed** → “你期待的服务器行为我办不到。”
* **418 I’m a teapot** → “我是个茶壶，不会给你煮咖啡（愚人节彩蛋）。”
* **421 Misdirected Request** → “请求发错服务器了。”
* **422 Unprocessable Entity** → “请求格式对，但语义有问题，处理不了。”
* **423 Locked** → “资源被锁住了。”
* **424 Failed Dependency** → “依赖的请求失败了，所以这个也失败。”
* **425 Too Early** → “太早发了，等一下。”
* **426 Upgrade Required** → “请升级协议再来。”
* **428 Precondition Required** → “必须带前置条件请求头。”
* **429 Too Many Requests** → “请求太频繁，慢点。”
* **431 Request Header Fields Too Large** → “请求头太大了。”
* **451 Unavailable For Legal Reasons** → “因为法律原因不能提供给你。”

---

## **5xx 服务器错误类（我的锅）**

* **500 Internal Server Error** → “我这边出错了，具体原因自己看日志吧。”
* **501 Not Implemented** → “我还没实现你要的功能。”
* **502 Bad Gateway** → “我找的上游服务器出错了。”
* **503 Service Unavailable** → “我现在忙不过来，稍后再试。”
* **504 Gateway Timeout** → “上游服务器响应太慢，我等不下去了。”
* **505 HTTP Version Not Supported** → “我不支持这个 HTTP 版本。”
* **506 Variant Also Negotiates** → “服务器配置循环了，谈不拢。”
* **507 Insufficient Storage** → “磁盘爆了，存不下。”
* **508 Loop Detected** → “检测到请求循环。”
* **510 Not Extended** → “请求需要扩展才能处理。”
* **511 Network Authentication Required** → “上网前先在网络认证页面登录。”
